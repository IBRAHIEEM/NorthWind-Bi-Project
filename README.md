# NorthWind-Bi-Project
A Business Intelligence project analyzing the Northwind Traders database to gain insights into sales and performance."

Northwind Data Warehouse & Power BI Project

📌 Project Overview

This project demonstrates the end-to-end Business Intelligence workflow using the Northwind dataset. The project starts with designing a Data Warehouse in SQL Server, followed by data transformation and preparation using Power Query, and finally building an interactive Power BI dashboard to analyze business performance.

🛠 Tools & Technologies

- SQL Server
- Data Warehouse Design
- SQL Queries
- Power Query
- Power BI
- DAX

📂 Project Workflow

1. Data Warehouse Development

- Extracted data from the Northwind operational database.
- Designed and implemented a Data Warehouse schema.
- Created Dimension Tables and Fact Tables.
- Applied ETL processes using SQL Server.

2. Data Transformation

- Connected the Data Warehouse to Power BI.
- Cleaned and transformed data using Power Query.
- Optimized data types and relationships.

3. Data Modeling

- Established relationships between fact and dimension tables.
- Created calculated measures using DAX.
- Built a star schema model for efficient reporting.

4. Dashboard Development

Designed an interactive dashboard to analyze:

Revenue Analysis

- Total Revenue
- Revenue Trends Over Time
- Revenue by Product Category

Profit Analysis

- Total Profit
- Profit Performance by Product and Category

Sales Quantity Analysis

- Quantity Sold
- Top-Selling Products

Customer Analysis

- Customer Distribution
- Customer Contribution to Revenue

Shipping Analysis

- Shipping Performance
- Orders by Shipping Method
- Delivery Insights

📊 Key Features

- Interactive Filters and Slicers
- Dynamic KPIs
- Drill-Through Analysis
- Custom Tooltips
- Trend Analysis
- Business Performance Monitoring

🎯 Project Objective

The goal of this project is to transform raw transactional data into meaningful business insights that support data-driven decision-making through a modern BI solution.
